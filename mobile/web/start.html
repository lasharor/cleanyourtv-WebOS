Pair a device

Use this phone as a remote for your TV. You only do this once.

1On the TV, in the manager app: Features > Phone remote > Pair a phone.

2Type the address it shows; the TV's own page then asks for the code.

Or scan the code on the TV with the camera: the app opens itself on the TV's page with the code filled in; choose a name for the phone and tap Pair.
