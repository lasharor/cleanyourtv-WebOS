DTS audio passthrough

TV software
Receiver on eARC / optical
Passthrough route
This switches the TV's eARC link to full-rate passthrough for players that use it (tvlauncher, Native Jelly). It plays nothing itself. Also set the TV's Digital Sound Output to Pass Through. It loads a kernel module from github.com/Mokto/earc_route (GPL-2.0, tested on an LG C1 only). Remove it, then restart the TV, to undo it completely.
OK twice to install or remove. Back goes to Home.
